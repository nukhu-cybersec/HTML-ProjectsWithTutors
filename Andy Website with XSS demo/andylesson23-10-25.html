  • JSON

    • JSON is a lightweight data-interchange format.
    • It is text-based, human-readable, and language-independent.
    • Commonly used for data exchange between a server and a web application.

  • jQuery

    • jQuery is a JavaScript library designed to simplify HTML DOM manipulation, event handling, CSS animations, and AJAX operations. It essentially wraps complex JavaScript code into simpler, more readable methods.

  • AJAX

    • AJAX is a technique that allows web pages to communicate with servers asynchronously—meaning data can be sent and received without reloading the entire page. Despite its name including "XML," AJAX commonly works with JSON, HTML, and plain text.
